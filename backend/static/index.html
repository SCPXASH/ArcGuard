Sensor placement (room map only — not sent to the ESP32)

Place sensors in the live 3D view ↗

Easiest: open the live 3D view, drag Sensors 1 and 2 to where they really are, press Auto-aim, and save the room — these fields fill in by themselves. A saved room remembers its sensor placement for next time.

Where each fixed sensor is and where it points, relative to the device: position in cm to the right (X) and to the front (Y); direction 0° = right, 90° = front, 180° = left, 270° = rear. Dragging a sensor in the 3D simulator updates these values, and the simulator follows changes made here.
